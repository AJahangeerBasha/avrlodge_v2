This directory contains the official logo assets for AVR Lodge Resort & Stay.

- **Size**: 240x80px
- **Use**: Primary logo for websites, business cards, letterheads
- **Background**: Light backgrounds
- **Colors**: Dark text with gold accents

### 2. Horizontal Logo (`avr-lodge-horizontal.svg`)
- **Size**: 320x60px
- **Use**: Website headers, horizontal layouts, email signatures
- **Background**: Light backgrounds
- **Layout**: Single line text layout

### 3. Icon Only (`avr-lodge-icon.svg`)
- **Size**: 64x64px
- **Use**: App icons, social media profiles, small spaces

### 4. Dark Version (`avr-lodge-dark.svg`)
- **Size**: 240x80px

## Design Elements

### Color Palette
- **Primary Dark**: `#111827` (Dark slate)
- **Secondary Dark**: `#374151` (Medium slate)
- **Accent Gold**: `#fbbf24` (Warm gold)
- **Text Gray**: `#6b7280` (Cool gray)
- **Light Gray**: `#9ca3af` (Muted gray)

### Typography
- **Main Title**: Serif font, bold, letter-spaced
- **Subtitle**: Serif font, normal weight
- **Tagline**: Sans-serif font, small size

### Icon Elements
- **Mountains**: Layered silhouettes representing Kolli Hills
- **Lodge**: Simple house shape with warm window lights
- **Stars**: Decorative elements suggesting hospitality
- **Gradient**: Subtle depth and premium feel

## Usage Guidelines

### Do's
- Use original proportions and colors
- Maintain clear space around logo (minimum 16px)
- Use appropriate version for background color
- Scale proportionally only

### Don'ts
- Don't modify colors or typography
- Don't stretch or distort the logo
- Don't use low-resolution versions
- Don't add effects or shadows

## File Formats
All logos are provided in SVG format for:
- Scalability without quality loss
- Small file sizes
- Web-friendly format
- Print-ready quality
